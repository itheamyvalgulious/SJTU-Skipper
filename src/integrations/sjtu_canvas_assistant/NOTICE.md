# Vendored SJTU Canvas client

This package is a vendored subset of
[`sjtu-canvas-assistant`](https://github.com/Aspirin0000/sjtu-canvas-assistant),
including the local new-portal adaptations used by the input plugin.

Original project license: MIT.  See `LICENSE` in this directory.

The original repository has been moved to the local, git-ignored `legacy/`
directory and is no longer required at runtime.
